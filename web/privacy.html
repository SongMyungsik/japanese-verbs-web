일본어 동사 활용 · 시행일 2026년 11월 1일

일본어 동사 활용 앱(이하 '앱')은 개인정보를 수집하지 않습니다.

수집하는 정보

앱은 이름, 이메일, 전화번호, 위치, 기기 식별자 같은 개인정보를 수집하지 않습니다. 회원 가입이 없고, 광고나 사용 통계 분석 도구도 쓰지 않습니다.

기기에 저장되는 정보

  • 복습 기록, 즐겨찾기, 퀴즈 설정은 사용자의 기기 안에만 저장되며 개발자에게 전송되지 않습니다.
  • 앱을 지우거나 앱 데이터를 지우면 이 정보도 함께 삭제됩니다.

읽어 주기 기능

일본어 읽어 주기는 기기에 설치된 음성 합성 기능을 사용합니다. 앱은 동사와 예문의 읽기만 음성 기능에 넘기며, 개인정보를 넘기지 않습니다.

인터넷과 제3자 제공

  • Android 앱은 인터넷 권한을 사용하지 않습니다.
  • 수집하는 정보가 없으므로 제3자에게 제공하는 정보도 없습니다.
  • 웹판은 실행에 필요한 파일과 글꼴을 GitHub Pages와 Google 서버에서 내려받습니다. 이 과정에서 해당 서비스가 IP 주소 같은 접속 정보를 처리할 수 있으며, 개발자는 이 정보를 받지 않습니다. 웹판의 기록은 브라우저 안에만 저장됩니다.
