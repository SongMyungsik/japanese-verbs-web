# 일본어 동사 활용

한국어 사용자를 위한 일본어 동사 활용 학습 앱입니다. 동사 597개, 활용형 13가지를 활용표와 퀴즈, 복습으로 익힙니다.

**바로 실행:** <https://songmyungsik.github.io/japanese-verbs-web/>

안드로이드폰과 아이폰의 브라우저에서 링크를 열면 설치 없이 실행됩니다.

## 사용 안내

- **홈 화면에 추가를 권장합니다.** 아이폰은 사파리 공유 버튼의 '홈 화면에 추가', 안드로이드는 크롬 메뉴의 '홈 화면에 추가'로 앱처럼 쓸 수 있습니다.
- **학습 기록은 그 기기의 그 브라우저에만 저장됩니다.** 다른 기기와 공유되지 않고, 브라우저 데이터를 지우면 함께 사라집니다.
- **아이폰 사파리에서 7일쯤 쓰지 않으면 기록이 지워질 수 있습니다.** 홈 화면에 추가해서 쓰면 피할 수 있습니다.
- **읽어 주기**는 기기의 음성을 쓰므로 기기마다 목소리가 다르고, 일본어 음성이 없으면 동작하지 않습니다.

## 개발

Flutter 3.41.5 기준입니다.

```
flutter pub get
flutter test
flutter run -d chrome
```

`main`에 푸시하면 GitHub Actions가 테스트를 돌리고 GitHub Pages에 배포합니다. 구조와 작업 순서는 [CLAUDE.md](CLAUDE.md)를 참고하세요.
